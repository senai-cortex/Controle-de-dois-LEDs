# Controle de LEDs com Botão

Projeto desenvolvido em Arduino utilizando um botão para controlar dois LEDs em uma sequência de estados.

## Funcionamento

* 1º aperto: acende o LED 1.
* 2º aperto: apaga o LED 1 e acende o LED 2.
* 3º aperto: apaga o LED 2.
* 4º aperto: acende novamente o LED 1 e reinicia o ciclo.
